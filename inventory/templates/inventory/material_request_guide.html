Material request guide

How to request warehouse material and follow it through fulfillment.

Start a material request
{% endif %}

1. Enter request details

Enter the requestor name and email, delivery location, and the required delivery date and time. Put any project or work-order reference in Notes when it will help the warehouse identify the work.

Urgent requests: select Urgent request only when the material needs immediate warehouse attention.

2. Choose from inventory

Search by part number, description, category, or storage location. Select Add, enter the quantity needed, and include line notes for any item-specific instructions.

You can add several material lines to one request. Review every quantity before submitting.

3. Decide how to handle shortages

If there is not enough stock, the available amount is reserved and you must choose what happens to the remainder:

  • Use available stock and cancel the rest — fulfill only what is currently available.
  • Request the rest when available — create a backorder for the shortage.
  • Ask Procurement to purchase the rest — route the shortage to Procurement.

4. Submit and keep the request number

Select Submit request. The confirmation and Request Board show the request number; include that number whenever you contact the warehouse.

If the page reports a problem, correct the highlighted field and submit again. Your in-progress form is saved in the same browser while you work.

5. Track your request

Open Request Board to see current status and fulfillment updates. Open the request for item details and delivery information. If the system asks you to confirm readiness or delivery, follow the instructions shown on that request.
